ELES SYSTEM — ПЕРЕНОС ПРОЕКТА

Текущая база: V3.
Задача: заново собрать и отполировать мобильный лендинг по исходным скриншотам, а не копировать кривую Tilda-оболочку.

ГЛАВНЫЙ ЭТАЛОН ВИЗУАЛА:
REFERENCE-SCREENS/ — исходные скриншоты сайта. Сверять буквально: композицию, размеры, интервалы, шрифт, радиусы, толщины линий, положение объектов, прозрачность и фон.

ИСТОЧНИК:
ORIGINAL-TILDA.html — старый HTML Tilda. Использовать для восстановления точного текста, изображений, исходных позиций и анимаций.
ORIGINAL-TILDA-ASSETS/ — полный набор сохранённых ресурсов старой страницы.

ВАЖНО:
- Сайт изначально проектировался под МОБИЛЬНЫЙ режим, не под desktop.
- Нижние черновые/невыходные блоки исходного Tilda HTML не использовать как эталон.
- Фото тренера должно быть исходным, как в ORIGINAL-COACH-PHOTO.png / assets/hero.png.
- На первом экране нужен исходный эффект затемнения/градиента поверх фото, чтобы внимание шло на заголовок и CTA.
- На секции сравнения нужен фон с тренирующимися девушками и стеклянные плашки (frosted glass / backdrop blur), как на iPhone.
- Визуальные решения не додумывать без необходимости: сначала ориентироваться на скриншоты.
- Текст восстанавливать из ORIGINAL-TILDA.html, а не писать новый маркетинговый текст.

ТЕКУЩИЙ КОД:
index.html + styles.css + script.js — V3.
index-onefile.html — полностью автономная версия, CSS/JS/картинки/шрифт встроены внутрь. Её можно использовать как единственный файл для простого статического хостинга.
